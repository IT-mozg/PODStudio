# Мокапи інтерфейсу — пісочниця

Ця папка ізольована від робочого сайту. Файли тут — статичні HTML-сторінки
для перегляду вигляду нового інтерфейсу, без реального функціоналу
(без Flask, без JS-логіки застосунку). Відкриваються прямо в браузері.

Реальний сайт (`views/templates/`, `views/static/`) не змінюється,
поки конкретний екран тут не буде затверджено.

`assets/style.css` — копія поточних продакшн-стилів (`views/static/style.css`
на момент створення). Правити вільно, на прод не впливає.
